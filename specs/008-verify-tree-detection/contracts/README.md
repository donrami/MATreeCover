# Contracts: Verify Tree Detection Quality

Date: 2026-08-05. Contracts define the observable interfaces of the
verification feature. They are referenced by the plan, the data model,
and the quickstart; the acceptance criteria in [tasks.md](../tasks.md)
(the `/speckit.tasks` output) test against them.

| Contract | Scope |
|----------|-------|
| [verify-sample.md](verify-sample.md) | Sample selection: algorithm, seed, strata, `verification/sample.jsonl` schema |
| [verify-ratings.md](verify-ratings.md) | Inspection criteria and the `verification/ratings.jsonl` schema |
| [verify-report.md](verify-report.md) | Report structure, flagging rule, disclosure requirements |
