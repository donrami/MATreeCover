# Contract: District Statistics and Popups

Feature 011, FR-006, FR-007, FR-009. The 38 official Stadtteile become
an interactive layer whose properties carry the derived statistics.

## District Layer

- Source `stadtteile`: GeoJSON `stadtteile.geojson` in the published
  bundle (EPSG:4326), generated by publish.py from the committed
  `verification/stadtteile.geojson` (GDI-MA, dl-de/by-2-0).
- Layer `stadtteile-fill`: fill layer, transparent (`fill-opacity` 0,
  no stroke), placed between `outside-mask` and `buildings-fill`.
  A transparent fill renders nothing but stays queryable, so district
  hit-testing works without changing the published render (SC-004).
- publish.py `available_sources` must include `'stadtteile'` or the
  style quarantine strips the source (research R-4).

## Statistics Derivation (publish time, deterministic)

Per district, joined by building centroid containment:

- `n_buildings`: count of buildings whose centroid lies in the
  district polygon (reference run: 93,022 assigned, 0 unassigned).
- `mean_value`: mean of `value` over buildings with a value, rounded
  to 1 decimal; `null` if the district has no valued buildings.
- `share_lt30`: 100 × (valued buildings with `value < 30` / valued
  buildings), rounded to 1 decimal.

Rounding: standard half-up at the 2nd decimal. Reference values in the
spec Goal section (Innenstadt 9.6 %, Niederfeld 34.5 %) are the
acceptance baseline; exact per-district numbers are recomputed by the
publish run and must match an independent recomputation within
0.5 pp (mean) / 1 pp (share) for all 38 districts (SC-002).

## District Popup

- Click on `stadtteile-fill` (no building hit at that point) opens the
  district popup (its own `maplibregl.Popup`, own className for
  styling, offset 8, closable).
- Content (German, values formatted like the existing popup, dot
  decimals, thin space as thousands separator):

  ```
  <div class="popup-label">Stadtteil</div>
  <div class="popup-value">Innenstadt</div>
  <div class="popup-label">Gebäude</div>
  <div class="popup-value">3 383</div>
  <div class="popup-label">Baumanteil im Durchschnitt</div>
  <div class="popup-value">9.6 %</div>
  <div class="popup-label">Anteil unter 30 %</div>
  <div class="popup-value">98.2 %</div>
  ```

- A district with `mean_value` null shows "keine Daten" instead of a
  fabricated number (spec Edge Cases). No district currently has zero
  buildings; the fallback is defensive.

## Click Arbitration

Rework the map-level click handler (currently: close building popup
when no `buildings-fill` feature is hit):

1. `queryRenderedFeatures(point, {layers: ['buildings-fill']})` hit →
   building popup (existing layer-filtered handler) wins; district
   popup closes if open.
2. No building, `queryRenderedFeatures(point, {layers:
   ['stadtteile-fill']})` hit → district popup opens; building popup
   closes.
3. Neither hit → both popups close.

This is the single arbitration point; the building layer-filtered
handler itself is unchanged.

## Building Popup Enrichment (FR-009)

- When the building popup opens, look up the district at the clicked
  coordinate via `map.querySourceFeatures('stadtteile')` (no fetch).
- If found, append two lines: "Stadtteil" → district `name`, and
  "Durchschnitt im Stadtteil" → `mean_value` formatted (or "keine
  Daten" when null).
- If not found (outside all districts), append nothing; the popup
  stays as today.
- The district mean here MUST equal the district popup's mean (same
  property, same formatting).

## Edge Cases

- Click on a district boundary line: centroid containment and click
  arbitration both use the polygon fill, so boundary clicks fall to
  whichever side the point is inside; no double popup.
- Popup on narrow screens: district popup has a max-width and wraps,
  never overflowing the viewport (FR-013).
